# Data-Science-Projects

This portfolio showcases projects focused on computer vision, predictive modeling, classification, regression, and real-world business problem solving. It serves as a centralized hub for transforming raw data into meaningful insights and building intelligent data-driven solutions through analytics and machine learning.

## 📁 Repository Structure

Based on the current contents of the repository, the projects are organized into the following domains:

*   **Object Detection**: Contains scripts for video processing, bounding box annotation, and class statistics tracking for computer vision tasks. 
*   **Gender Classification**: Includes model training and analysis notebooks focused on demographic classification.
*   **Linear Regression Models**: Features predictive modeling datasets and analysis, such as the Hourly Pay dataset.
