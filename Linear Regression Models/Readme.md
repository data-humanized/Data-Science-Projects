# Linear Regression Salary Prediction

This project demonstrates how to use Linear Regression in Python (Scikit-learn) to predict hourly salary based on education and professional training.

---

## Project Objective

To predict **Hourly Rate** using:
- Education (years)
- Training (0 = No, 1 = Yes)

---

## Dataset

The dataset contains 100 rows with the following columns:

| Column      | Description                     |
|------------|---------------------------------|
| Education  | Number of years of education    |
| Training   | 1 = Yes, 0 = No                |
| HourlyRate | Target variable (salary/hour)   |

---

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
